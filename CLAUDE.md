## ⚠️ Next.js version is non-standard — read docs first

This repo pins `next@16.3.3`, a version with breaking changes not reflected in your training data.
**Before writing any App Router code, read `AGENTS.md` and the relevant guide under
`node_modules/next/dist/docs/01-app/`** — don't assume APIs from earlier Next.js versions still apply.

Notable breaking/new behavior already confirmed in this version's docs (do not treat these as typos):

- **Middleware is renamed Proxy.** The file is `proxy.ts` (project root or `src/`), exporting a `proxy`
  function (default or named export) instead of `middleware`. Same purpose/API shape otherwise.
- **`PageProps<'/route'>` / `LayoutProps<'/route'>`** are global, auto-generated typed-route helpers
  (no import needed) for `page`/`layout` components — generated by `next dev`/`next build`/`next typegen`.
  `app/layout.tsx` already uses `LayoutProps<"/">`; follow this pattern instead of hand-writing
  `{ children: React.ReactNode }` props.
- **Cache Components** (`cacheComponents: true` in `next.config.ts`) is the newer caching model built
  around the `use cache` directive (`next/cache`'s `cacheLife`/`cacheTag`) plus `<Suspense>` for
  uncached/runtime data (`cookies()`, `headers()`, `searchParams`). It is **not enabled** in this repo's
  `next.config.ts` yet — if you enable it, expect the dev overlay to flag uncached/runtime reads and
  random values (`Math.random()`, `Date.now()`, `crypto.randomUUID()`) that aren't behind `use cache` or
  `connection()` + `<Suspense>`.

## Architecture

- **App Router only**, no `src/` directory — routes live directly under `app/`.
- Only `app/layout.tsx` (root layout, required `html`/`body`) and `app/page.tsx` (home page, still the
  CNA placeholder) exist so far — no other routes, components, or data layer yet.
- Path alias `@/*` → repo root (`tsconfig.json`).
- Styling: Tailwind CSS v4 via `@tailwindcss/postcss`, configured in CSS (`app/globals.css` uses
  `@import "tailwindcss"` and `@theme inline`) — there is no `tailwind.config.*` file to edit.
- Fonts: `next/font/google` (Geist / Geist Mono) wired up as CSS variables in the root layout.
- Linting: flat ESLint config (`eslint.config.mjs`) composing `eslint-config-next`'s
  `core-web-vitals` and `typescript` rule sets.
